# Anusha H P — Professional Azure Portfolio

## Project structure
- frontend/index.html — portfolio website
- frontend/style.css — complete responsive design
- backend/app.py — Flask backend API
- backend/requirements.txt — Python dependencies

## Test locally
1. Extract the ZIP completely.
2. Open the extracted `Anusha_Professional_Portfolio` folder.
3. Open `frontend`.
4. Double-click `index.html`.

## Azure deployment
Frontend: Azure Static Web Apps, App location `/frontend`.
Backend: Azure App Service, Python + Flask.
